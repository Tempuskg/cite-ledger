Cite Ledger

Reference-list checks against Crossref, in VS Code-compatible editors and on the command line.

Install from the VS Code Marketplace or Open VSX, or download the VSIX from the v0.1.0 release. Source is on GitHub.

What it checks

  • Reads .bib files, LaTeX thebibliography lists and Markdown reference sections.P7
  • Flags references whose DOI does not resolve in Crossref.P1
  • Flags retractions, corrections and expressions of concern recorded in Crossref, including Retraction Watch data.P2
  • Shows where an entry's title, year or first author differs from the Crossref record.P3
  • Marks references with no matching Crossref record as unverified.P4
  • Runs on your machine and sends only the reference details it looks up to Crossref.P5
  • Makes no AI model calls: every check is a lookup in Crossref's records.P9
  • A Pro licence check sends your licence key, and no reference data, to Polar, the payment provider.P10

Every finding links to its evidence and says how it could be wrong. Each claim above is backed by a test that must pass before a release: see the claim register.

What it cannot check

  • Does not check DOIs registered outside Crossref, for example DataCite.L1
  • Crossref's retraction data can miss some retractions.L2
  • 'Unverified' means no matching record was found, not that the reference is fabricated.L3

More detail, including exactly what leaves your machine: limits.

Free and Pro

  • Single-file checks are free; Pro is a one-time licence.P6
  • Pro adds workspace-wide scans, CLI/CI exit codes, Markdown, CSV and JSON reports, and closest-match suggestions.P8

Pro costs USD $12, as listed on the Polar product page ("This is a one-time charge").
